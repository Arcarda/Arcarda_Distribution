# Arcarda Mod Distribution (Production)

Welcome to the Arcarda Mod Suite distribution repository. This contains the production-ready binaries for the Arcarda mod ecosystem.

## Mod Suite Contents

- **ArcardaCore**: Core library for Arcarda's mods.
- **ArcRifts**: A REVITALIZED Dimensional Doors overhaul for GTNH 1.7.10 with high-fidelity textures and UI skinning.
- **GTNH-RoR**: Risk of Rain mechanics integrated for GTNH survival.
- **PollutionMutation**: Pollution-based survival and mutation mechanics.

---

## Installation & Updates

1. **Clone the Repo** (if you haven't already):
   ```bash
   git clone https://github.com/Arcarda/Arcarda_Distribution.git
   ```
2. **Install Git LFS**:
   - Install from [git-lfs.github.com](https://git-lfs.github.com/).
   - Run `git lfs install` in your terminal.
3. **One-Click Sync**:
   - Navigate to the repository folder.
   - Right-click `sync_mods.ps1` and select **Run with PowerShell**.
   - Your `mods/` folder will be automatically synchronized with the latest production versions.
